## TOP FINDINGS (new — not in GROUND_TRUTH.md)

### 1. Profile save is 100% broken — HTTP verb mismatch (BLOCKER for F8)
`lib/api-spec/openapi.yaml:133-149` declares `put:` for `updateUserProfile` → Orval generates `method: "PUT"` (`lib/api-client-react/src/generated/api.ts:484`). The backend only registers `@router.post("/user/profile")` (`api/routes/user.py:19`) — no PUT handler. Every save from `pages/profile.tsx:42` and `pages/feed.tsx:108` gets a **405**, silently swallowed (`feed.tsx:108-117` mutation has no error handler). Not "siloed" as GROUND_TRUTH said — **dead**.
**Fix:** add `@router.put` (or change the spec verb and regenerate the client). Verify with `curl -X PUT`.

### 2. Personalization is structurally impossible (BLOCKER for F8)
`agents/analyze_agent.py:220`: `result = analyze_item(client, enriched, sop)` — the `user_profile` param (accepted at `:95`) is **never passed**. Prompt always gets "Not provided" (`:134`); `prompts/analyze.txt:47` then instructs empty `personal_impact`. Cards are generated once globally, not per-user — even a perfect profile flow changes nothing. `prompts/personal_impact.txt` exists but is **never read by any code** (dead file).
**Fix requires a design decision:** per-user re-personalization pass at read time is the natural architecture (analyze-time personalization doesn't scale past one user).

### 3. Live NVIDIA API key in plaintext (LOCAL ONLY — not on GitHub, see §6)
`artifacts/newslens-backend/.env:2`: `COMMANDCODE_API_KEY=nvapi-…` (real key format, not placeholder).
**Status 2026-07-05:** verified NOT in the public GitHub repo (never committed, not in history). `.gitignore` did not exclude `.env` — **fixed 2026-07-05** (now ignores `.env`, `.env.*`, `*.db`; keeps `.env.example`). **User action still pending: rotate the key at build.nvidia.com.**

### 4. Semantic dedup resets on every restart
`agents/clean_agent.py:33-36`: `_recent_embeddings` / `_recent_hashes` are module-level in-memory lists. `is_duplicate()` (`:85-111`) never queries `clean_items.dedup_hash` back from the DB. Every process restart → dedup state zero → previously-seen near-duplicates re-enter.

### 5. Classify + QualityGate silently deviate from specs
- `agents/classify_agent.py:38-43`: company weight `0.02` capped at 5 companies, vs spec §5.4's `0.1` uncapped — company mentions barely move importance.
- `pipeline/quality_gate.py:47-52`: spec §5.8's independent OR discard rules were AND-narrowed. A low-confidence numberless card with any winner/loser now passes; a <20-word summary passes if the headline is ≥5 words.
- **"hold" is a black hole:** `quality_gate.py` computes a `"hold"` verdict but there's no status column on `cards`, no review route, no UI. Held cards are re-evaluated identically forever and can never resolve. Zero references to "hold" outside quality_gate.py.

## Other bugs & defects (all verified with file:line)

- **`metadata_json` is not JSON**: `agents/ingest/rss_agent.py:85`, `substack_agent.py:81`, `reddit_agent.py:105` use `str(metadata)` (Python repr) not `json.dumps`. Write-only today; first future `json.loads` reader crashes on every row.
- **Dead no-op in Reddit ingest**: `reddit_agent.py:56-57` — `if post.is_self is False and not post.selftext: pass` — clearly meant `continue` (skip textless link posts); inert.
- **CORS invalid combo**: `api/main.py:30-36` — `allow_origins=["*"]` + `allow_credentials=True`. Browsers reject credentialed responses under `*`. Bites when cookie auth is added.
- **OpenAPI drift on `/cards`**: spec declares `domain, search, limit, page` (`openapi.yaml:40-58`); backend implements `domain, geo, confidence, page, limit` (`api/routes/cards.py:72-77`) — no `search`. Typed client can only send `domain` → geo/confidence filtering is client-side over one hardcoded `page:1, limit:50` fetch (`feed.tsx:47-54`); `has_more` is never used; pagination never triggers.
- **`get_personalized_cards` uses only `sectors[0]`** (`cards.py:132-136`) — rest of user's declared exposure ignored.
- **Two incompatible profile vocabularies for same DB columns**: `OnboardingModal.tsx:9-32` ("Salaried Employee", "Mutual funds / SIPs", Indian city dropdown) vs `profile.tsx:74-112` ("salary"/"freelance", "conservative"/"aggressive", placeholder "e.g. San Francisco"). Even after fixing bug #1 they write mutually unintelligible data.
- **Feed route bypasses app shell**: `App.tsx:23` — `/` not wrapped in `<Layout>`; header profile icon reopens OnboardingModal (`feed.tsx:125-127`), the API-backed `/profile` page is effectively undiscoverable.
- **Seed data indistinguishable + can re-enter forever**: `db/seed.py:365-369` `seed_if_empty()` re-seeds 15 demo cards whenever zero live cards exist (e.g. after an LLM outage); no `is_seed` flag. Also key typo `"summary_json"` at `:294`, defensively covered at `:385`.
- **`/sources/status` "items_today" is a 7-hour window** (`api/routes/sources.py:27`), misleadingly named in `api/models.py:82` and `openapi.yaml:364`.
- **`/pipeline/run` + `/pipeline/logs` world-callable** — spec §6 says "Dev only"; no gating (`api/routes/sources.py:65-83`). No rate limiting anywhere.
- **Sequential sync LLM calls (GROUND_TRUTH Fix 3 — still unfixed)**: `extract_agent.py:106,118,168` (`def run()`, `for` loop, `time.sleep`); same in `analyze_agent.py:184-251`. No `asyncio.gather` anywhere. Doesn't block the API event loop (runs in BackgroundTasks/APScheduler) but serializes the pipeline.
- **`cards.enriched_id` has no FK constraint** (`db/schema.sql:66` vs `specs.md:169`).
- **Dead weight to delete**: Gemini remnants (`requirements.txt:4` `google-genai`, `config/settings.py:70-73`, `.env.example` GEMINI vars); `.env.example:3` wrongly says default is OpenRouter (it's NVIDIA NIM, `settings.py:34-37`); `artifacts/api-server/` (generic Express boilerplate, unused); `lib/db/` (Drizzle scaffold, schema literally `export {}`); `prompts/personal_impact.txt` (never read).

## What's BUILT and works (credit where due)
- All 8 pipeline stations wired (`pipeline/orchestrator.py:133-149`), per-stage try/except + `pipeline_runs` logging; `status='pending'` polling makes failed runs naturally resumable — real, load-bearing resilience.
- Extract/Analyze: retry-once-on-invalid-JSON per spec §5.3 (`extract_agent.py:86-103`, `analyze_agent.py:149-166`); enum coercion instead of discard (sensible, unspecced).
- Enrichment: yfinance + commodities + FRED with 4h DB-backed `enrichment_cache`; all failures degrade gracefully.
- API: all 9 routes present; SQL parameterized everywhere (no injection); Pydantic-validated swipe input.
- APScheduler `BackgroundScheduler`, `max_instances=1` — no overlapping runs.
- Frontend: Swipe (Framer Motion physics, keyboard, **`prefers-reduced-motion` fully respected** — `SwipeMode.tsx:175,186-194`), Reel (scroll-snap + real progress indicators), filters, confidence badge with aria-label, onboarding matching UI_SPEC §8 exactly, Nerd Mode locked-stub per §7, localStorage persistence of mode/filters.

## SPEC GAPS — what the specs fail to specify
- **User identity model** (no auth → how does user_id exist? code answered "default_user"; no doc admits single-tenant).
- **Personalization architecture** — when does per-user impact happen? Analyze-time doesn't scale; read-time re-personalization pass needs to be specced. Biggest unwritten design decision.
- **Dedup persistence semantics** ("last 500 embeddings" — per-process? per-run? global?).
- **Card lifecycle** — no expiry/retention/archival; `cards` grows unboundedly; "hold" never resolves.
- **Pagination contract; rate limiting; per-item error surfacing** (failures visible only as aggregate counts in `pipeline_runs`); **prompt versioning** (no record of which prompt version produced which card); **seed-vs-real provenance**.
- **Testing strategy — ZERO automated tests, no CI in the entire repo** (`testapi.py` is a manual LLM-connectivity CLI, not a test).
- **Tool Use spec must be rewritten OpenAI-style** (`tools=[...]`) — CLAUDE.md's Gemini `FunctionDeclaration` plan is moot post-NIM-migration.

## Critique (the meta-lessons)
1. **The two differentiators (quantified impact + personalization) are exactly the two things that don't work end-to-end.** Everything that works is commodity. Reviewers tap the core promise first.
2. **Contract drift is the recurring failure mode** (OpenAPI vs backend, spec formulas vs code, two profile UIs, five contradicting docs). Highest-leverage structural fix: generate/contract-test OpenAPI from FastAPI instead of hand-maintaining; collapse docs to GROUND_TRUTH + NEXT_STEPS.
3. **Zero tests is the silent multiplier** — every bug above would've been caught by one thin integration test + per-stage unit tests.
4. **No local git** = no undo, no history. Fix via step 2.
