# NewsLens — UI Specification

Version: 1.0  
Applies to: Web Frontend (v1)

---

## 1. Design Philosophy

**One insight. Full screen. No noise.**

Every element on the card earns its place by answering one of three questions:
- What happened and how big is it?
- Who wins and who loses?
- What does it mean for me?

Everything else is chrome — and chrome should disappear.

## 4. Tinder Mode (Swipe)

### 4.1 Layout

Cards centered horizontally and vertically in the remaining viewport.  
Card dimensions: `min(480px, 90vw)` wide, `min(680px, 85vh)` tall.  
Cards behind the active card are visible as a stack (2 cards, slightly offset and scaled down).

```
         [Card -2: barely visible, scale 0.92]
       [Card -1: slightly visible, scale 0.96]
    [ACTIVE CARD: full size, full opacity]
```

### 4.2 Card Anatomy

```
┌───────────────────────────────────┐
│  [Domain Pill]       [Badge]      │  ← Row 1: metadata
│                                   │
│                                   │
│  Headline                         │  ← Row 2: headline (DM Serif, 26px)
│  (2 lines max, truncate)          │
│                                   │
│  Summary text                     │  ← Row 3: summary (DM Sans, 15px)
│  (60 words max, 4 lines)          │
│                                   │
│  ┌────────────┐ ┌───────────────┐ │
│  │ KEY NUMBER │ │ TIME HORIZON  │ │  ← Row 4: data chips
│  └────────────┘ └───────────────┘ │
│                                   │
│  ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔ │  ← Divider
│                                   │
│  ✅  Winner                       │  ← Row 5: winner chip
│      Who · Why · Magnitude        │
│                                   │
│  ❌  Loser                        │  ← Row 6: loser chip

│                                   │
│  👤 Your Impact                   │  ← Row 7: personal (only if profile)

│                                   │
```

### 4.3 Domain Pills

| Domain | Color | Icon |
|---|---|---|
| Finance | `--accent-finance` | 📈 |
| Tech | `--accent-tech` | ⚡ |
| Geopolitics | `--accent-geo` | 🌐 |
| Environment | `--accent-env` | 🌱 |

### 4.4 Confidence Badge

Top-right of card. Pill shape.
- `HIGH` — green dot + "High Confidence"
- `MEDIUM` — amber dot + "Est."
- `LOW` — grey dot + "Uncertain"

### 4.5 Swipe Interaction

**Mouse/Touch:**
- Drag card left or right
- At 30% of card width displacement → show directional hint overlay
- At 60% displacement → card flips off screen with momentum physics
- Keyboard: `←` = skip, `→` = save, `↑` = expand detail, `↓` = close detail

**Overlay hints:**
- Dragging left → red tint on card + "✕ SKIP" label fades in
- Dragging right → green tint on card + "★ SAVE" label fades in

**Stack animation:**
- When active card leaves → card behind it scales up from 0.96 → 1.0 with spring easing
- New card slides up from below into the back of the stack

### 4.6 Detail Expand (↑ swipe up or click card body)

Card expands to show:
- Full India / USA / China angles (tab switcher)
- Source link
- Enrichment data used (stock price at time of analysis)
- Collapse back on ↓ or click outside

## 5. Reel Mode (Scroll)

### 5.1 Layout

Full-width, full-viewport-height cards. Vertical stack.  
CSS `scroll-snap-type: y mandatory` on container.  
Each card: `scroll-snap-align: start`.

Card content same as Tinder mode but horizontally centered, wider layout.  
On desktop: card max-width 640px, centered.  
On mobile: full width.

### 5.2 Navigation

- Scroll up/down (mouse wheel, touch swipe)
- Snap to next card on scroll
- Progress indicator: thin vertical bar on right edge (like Stories)
- Dot indicators at bottom: current position in feed

### 5.3 Auto-advance (Optional, Off by Default)

Toggle in header: auto-advance every 8 seconds.  
Countdown ring animation on card corner.  
Tap to pause.

## 6. Filter Bar

Below the header. Sticky on scroll.

### 6.1 Domain Tabs

```
[ All ]  [ 📈 Finance ]  [ ⚡ Tech ]  [ 🌐 Geopolitics ]  [ 🌱 Environment ]
```

Active tab: bottom border in domain accent color.  
Inactive tabs: `--text-secondary`.

### 6.2 Geography Pills

```
[ 🌍 Global ]  [ 🇮🇳 India ]  [ 🇺🇸 USA ]  [ 🇨🇳 China ]
```

Multi-select — user can combine (e.g. India + China). Selected pill: filled background.

### 6.3 Confidence Filter

Default: High + Medium only.  
Toggle: `[ Show uncertain cards ]` — when enabled, adds Low confidence cards with a grey border treatment.

## 8. Onboarding Modal

Shown on first visit (no profile in localStorage).  
Can be dismissed (shows generic cards without personalization).

### 8.1 Step Flow

5 steps, progress bar at top.

**Step 1 — Income Type**  
"How do you primarily earn?"  
Options: Salaried Employee | Business Owner | Investor / Trader | Student

**Step 2 — Sector Exposure**  
"Which sectors are you exposed to?" (multi-select checkboxes)  
IT / Software | Banking & Finance | Real Estate | Manufacturing | Healthcare | Education | None / Not sure

**Step 3 — Investment Profile**  
"How is your money currently invested?"  
Mostly FDs & savings | Mutual funds / SIPs | Direct stocks | Crypto | No investments

**Step 4 — Your City**  
Dropdown: Mumbai | Delhi | Bengaluru | Hyderabad | Chennai | Pune | Ahmedabad | Kolkata | Other

**Step 5 — Companies You Watch**  
Free text: "Any specific companies? (optional)"  
Placeholder: "e.g. Infosys, Tata Motors, Apple..."

**Final screen:**  
"Your feed is personalized. We'll tell you exactly how each story affects someone like you."  
`[Start reading →]`

## 9. Empty and Loading States

### 9.1 Loading (cards being fetched)

Skeleton card with shimmer animation. Same dimensions as real card.  
Text: "Fetching latest intelligence..." (small, below card)

### 9.2 Empty Feed (no cards match filters)

Centered in card area:
```
    📭
    No cards match your current filters.
    [Reset filters]
```

### 9.3 End of Feed

After last card in swipe mode:
```
    ✓ You're caught up.
    Next update in [X hours].
    [View saved cards]
```

## 10. Responsive Breakpoints

| Breakpoint | Layout changes |
|---|---|
| < 480px (mobile) | Cards full-width; header simplified; filter bar scrollable horizontally |
| 480–768px (tablet) | Cards 90vw; mode toggle stays |
| 768–1024px (laptop) | Cards max 480px, centered; filter bar full |
| > 1024px (desktop) | Cards max 520px; consider showing 2 stats in a row on card |

---

## 11. Animations and Motion

| Interaction | Animation |
|---|---|
| Card enter | Slide up from 20px below + fade in (200ms, ease-out) |
| Card swipe dismiss | Rotate + translate + fade out (300ms, ease-in) |
| Card stack advance | Scale 0.96 → 1.0 (250ms, spring) |
| Filter tab switch | Underline slides (150ms) |
| Mode switch | Cross-fade between card areas (200ms) |
| Skeleton shimmer | Linear gradient scan, 1.5s loop |
| Onboarding step | Slide left in/out (200ms) |

Respect `prefers-reduced-motion`: replace all transitions with instant when set.

---

## 12. Accessibility

- All interactive elements keyboard-focusable
- Swipe actions have equivalent button controls (✕ Skip, ★ Save)
- Domain/geo filter elements are proper `<button>` or `<input type="checkbox">`
- Confidence badge has `aria-label` explaining meaning
- Minimum contrast ratio 4.5:1 for all text
- Focus ring visible and styled (2px `--accent-finance` outline)
